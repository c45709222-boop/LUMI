# Lumi's Secret Archive — A3 Website Master Build

This is the A3 website master build for the COMU1140 transmedia project **The Cat That Eats Secrets**.

## Structure
- `index.html` — Case opening / archive home
- `timeline.html` — non-linear investigation timeline
- `evidence.html` — interactive evidence room
- `media-map.html` — transmedia integration hub
- `feed-lumi.html` — audience secret submission
- `theory.html` — participatory theory building
- `community.html` — user-generated community archive prototype
- `style.css` — shared visual system
- `app.js` — interactions and local prototype storage

## Important A3 workflow
The site is deliberately built so the other team members' final media can be inserted later without redesigning the information architecture.

### Team media insertion points
1. `media-map.html` — connect actual Instagram/video/hand-drawn outputs.
2. `evidence.html` — replace the unidentified evidence slot with a real original team asset.
3. Additional original Photoshop assets can be placed in `media/` and linked into the relevant evidence cards.

## Original-content rule
Do not submit stock images or old media. For A3, replace/add only original assets produced during the course period. The CSS cat portrait on the homepage is a temporary interface illustration and should not be treated as the final required original image asset.

## Adobe evidence plan
Use Photoshop for substantive production of the final archive visuals. Keep:
- original source photos/drawings
- `.psd` files with layers
- screenshots of the Photoshop workspace/layers
- exported final assets
- at least two visible versions of the same asset

The website itself can then use those exported assets.

## AI disclosure
This build uses AI-assisted technical development. The final submission should disclose the actual AI use honestly and align the statement with the team's updated AI Charter. Do not invent process evidence or claim a workflow that did not happen.

## Audience participation
The website contains three participation mechanisms:
- Feed Lumi a secret
- Build a theory
- Add a community record

These are intentionally tied to the storyworld rather than generic comments/follows.

## Local storage note
The secret and community interactions are currently stored only in the visitor's browser via `localStorage`. This is suitable as an interaction prototype. If the final project requires real public UGC, connect an approved service and add appropriate privacy wording.


## A3 media additions
The `media/` folder now contains the eight visual assets supplied for this update. They are placed across the Evidence Room, Media Map and home page with captions and alt text. Instagram-style screenshots are presented as storyworld posts/mock-ups, not as verified real-world records.
